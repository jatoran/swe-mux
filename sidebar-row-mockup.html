2. Duration semantics

One field, meaning shifts with state. Ready shows the last completed turn, so it is static and never ticks. Everything is capped at four characters so the right edge forms a real column.

awaiting  5melapsed since it started waiting, ticking
ready  72show long the last turn took, static
